# Pearls AQI Predictor

An end-to-end ML system that forecasts Karachi's Air Quality Index (AQI) for the next 3 days using live weather and pollutant data. The project features automated data pipelines, multi-model comparison (XGBoost selected as production model), and an interactive dashboard with SHAP explainability and health alerts.
